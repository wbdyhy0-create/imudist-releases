# Imudist: הורדות

כאן מורידים את גרסת הניסיון של Imudist ל-Windows ול-Mac. הקישורים **קבועים** ותמיד מובילים לגרסה האחרונה.

## גרסת ניסיון (180 יום מההפעלה הראשונה)

| מערכת | הורדה |
|---|---|
| Windows | [Imudist-Trial-Windows.exe](https://github.com/wbdyhy0-create/imudist-releases/releases/download/latest-trial/Imudist-Trial-Windows.exe) |
| Mac עם שבב Apple (M1 ומעלה) | [Imudist-Trial-Mac-AppleSilicon.dmg](https://github.com/wbdyhy0-create/imudist-releases/releases/download/latest-trial/Imudist-Trial-Mac-AppleSilicon.dmg) |
| Mac עם מעבד Intel | [Imudist-Trial-Mac-Intel.dmg](https://github.com/wbdyhy0-create/imudist-releases/releases/download/latest-trial/Imudist-Trial-Mac-Intel.dmg) |

## איך מתקינים

1. שומרים את המסמכים הפתוחים וסוגרים את התוכנה.
2. מורידים את הקובץ המתאים ומתקינים **מעל** הגרסה הקיימת. המסמכים וההגדרות נשארים.
   - **Windows:** מריצים את הקובץ. אם מופיע "Windows protected your PC": לוחצים "מידע נוסף" ואז "הפעל בכל זאת".
   - **Mac:** פותחים את הקובץ וגוררים את Imudist לתיקיית Applications. בפעם הראשונה לוחצים ימני על התוכנה ואז "פתח".
3. לא בטוחים איזה Mac יש לכם? תפריט Apple, ואז "אודות ה-Mac".

אחרי ההתקנה הראשונה התוכנה מתעדכנת לבד: כשיוצאת גרסה חדשה מופיעה בה הודעה, ולחיצה אחת מתקינה אותה (גם מהתפריט **עזרה ← בדוק עדכונים…**).

כל הגרסאות הקודמות נמצאות ב[עמוד ההפצות](https://github.com/wbdyhy0-create/imudist-releases/releases).
