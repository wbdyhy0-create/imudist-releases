## איך מתקינים

1. **Windows:** מריצים את הקובץ. אם מופיע "Windows protected your PC": לוחצים "מידע נוסף" ואז "הפעל בכל זאת".
2. **Mac:** פותחים את הקובץ וגוררים את eMood לתיקיית Applications. בפעם הראשונה macOS חוסם את התוכנה (היא עוד לא רשומה אצל Apple):
   - בהודעה לוחצים **Done** (לא "Move to Trash"), פותחים **הגדרות המערכת ← פרטיות ואבטחה**, גוללים למטה, לוחצים **Open Anyway** ("פתח בכל זאת") ומאשרים בסיסמה. פעם אחת בלבד.
   - ב-macOS 14 ומטה אפשר גם ללחוץ ימני על התוכנה ואז "פתח".
   - אם כתוב שהתוכנה "פגומה": פותחים את Terminal, מריצים `xattr -dr com.apple.quarantine "/Applications/eMood Trial 30.app"` ופותחים שוב.
3. לא בטוחים איזה Mac יש לכם? תפריט Apple, ואז "אודות ה-Mac".

אחרי ההתקנה הראשונה התוכנה מתעדכנת לבד: כשיוצאת גרסה חדשה מופיעה בה הודעה, ולחיצה אחת מתקינה אותה (גם מהתפריט **עזרה ← בדוק עדכונים…**).

כל הגרסאות הקודמות נמצאות ב[עמוד ההפצות](https://github.com/wbdyhy0-create/imudist-releases/releases).

פרטיות: בלחיצה על קישור ההורדה נרשמים, לצורך ספירת הורדות בלבד, השעה, המדינה (בקירוב), המערכת שבחרתם ופרטי הדפדפן. כתובת האינטרנט שלכם אינה נשמרת.
